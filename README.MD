## ドキュメントの編集

### 必要なもの

- テキストエディタ（Visual Studio Code推奨）
- Git

### 編集方法

1. リポジトリをクローン:
   ```bash
   git clone https://github.com/mkt-kuno/DigitShowDoc.git
   cd DigitShowDoc
   ```

2. Markdownファイルを編集:
   - 任意のテキストエディタで `.md` ファイルを編集
   - VS Codeでは `Ctrl+Shift+V` でプレビュー表示可能

3. 変更をコミット・プッシュ:
   ```bash
   git add .
   git commit -m "ドキュメントの更新"
   git push
   ```

詳細は [markdown_guide.md](markdown_guide.md) を参照してください。
