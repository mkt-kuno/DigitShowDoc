# DigitShowModbusの説明書

DigitShowModbus は、三軸圧縮試験機の計測・制御ソフトウェアです。
本リポジトリはそのドキュメントを格納しています。

## はじめに

DigitShowModbus（DSM）は、  
Windows 3.1/95 時代に東京大学 本郷地盤研 博士卒の中央開発株式会社 王 林（LIN Wang）氏が作成した DigitShow を参考に、  
Windows 2000 時代に東京大学 本郷地盤研 助手 本多 剛（HONDA Tsuyoshi）氏が作成した DigitShowBasic を参考に、  
Windows 11 時代に東京大学 生産技術研究所 一般技術職員 久野 洵（MAKOTO Kuno）氏が、  
現代的な C/C++ 仕様に対応したソフトウェアとして内部を大幅に加筆修正し、  
既存の Contec / Interface ボードへの依存を解消するべく独自開発した ModbusRTU ボードに対応させた生研式三軸試験機向けのソフトウェアです。
生研式三軸試験機とは、東京大学生産技術研究所(後に複合技術研究所に所属)の佐藤 剛司氏により開発された、
ACサーボモータ＋ダブルクラッチ式による、軸応力抜けを防ぎながら押し引き方向を変更できる機構を有した載荷装置による三軸試験機を指します。

- **現在このドキュメントが主に対象とする機能**: 生研式三軸試験装置を使った、飽和三軸圧縮試験およびLDTによる鉛直微小繰り返し載荷の運用 
- **改造版の例**: 弾性波計測の自動化や、不飽和三軸圧縮試験への適用などがあります。ただし、それらは標準版とは目的・実装・保守範囲が異なる場合があります。
