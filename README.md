# DigitShowDoc

DigitShowModbus は、三軸圧縮試験機の計測・制御ソフトウェアです。
本リポジトリはそのドキュメントを格納しています。

## はじめに

DigitShowModbus（DSM）は、Windows 3.1/95 時代に東京大学 本郷地盤研 博士卒の中央開発株式会社 王 林（LIN Wang）氏が作成した DigitShow を参考に、Windows 2000 時代に東京大学 本郷地盤研 助手 本多 剛（HONDA Tsuyoshi）氏が作成した DigitShowBasic を参考に、Windows 11 時代に東京大学 生産技術研究所 一般技術職員 久野 洵（MAKOTO Kuno）氏が、現代的な C/C++ 仕様に対応したソフトウェアとして内部を大幅に加筆修正し、既存の Contec / Interface ボードへの依存を解消するべく独自開発した ModbusRTU ボードに対応させたソフトウェアです。

- **現在このドキュメントが主に対象とする機能**: 生研式の三軸試験装置を使った、飽和三軸圧縮試験およびLDTによる鉛直微小繰り返し載荷の運用 `@todo: 正式な試験名・表記を確認`
