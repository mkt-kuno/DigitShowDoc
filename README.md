# DigitShowDoc

DigitShowModbus は、三軸圧縮試験機の計測・制御ソフトウェアです。
本リポジトリはそのドキュメントを格納しています。

## はじめに

DigitShowModbus（DSM）は、**生研式の三軸試験装置を用いた土質試験の計測・制御を行うためのWindows向けソフトウェア**です。卒業論文・修士論文等で概要を簡潔に記す必要がある場合は、必要に応じてこの説明を適宜調整して利用してください。

- **ライセンス**: DigitShowModbus 本体は**クローズドソース**です。本リポジトリで公開しているのはドキュメントです。
- **現在このドキュメントが主に対象とする機能**: 生研式の三軸試験装置を使った、飽和三軸圧縮試験およびLDTによる鉛直微小繰り返し載荷の運用 `@todo: 正式な試験名・表記を確認`
- **改造版の例**: 弾性波計測の自動化や、不飽和三軸圧縮試験への適用などがあります。ただし、それらは標準版とは目的・実装・保守範囲が異なる場合があります。

<p><strong><span style="color:red;">WARNING</span></strong>: コードを書き換えて運用する場合は、必ず関連ドキュメントを十分に読み、<strong>Gitで変更履歴を管理しながら</strong>、自己の責任において実施してください。改造版・派生版の動作、保守、実験結果の妥当性について、本ドキュメントは保証しません。</p>
