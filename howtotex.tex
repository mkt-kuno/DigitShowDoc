\chapter{付録：Pandoc対応LaTeXによる本ドキュメントの編集方法}

\section{概要}
本ドキュメントは``Pandoc対応LaTeX''で記述されています。これは、PandocのLaTeXリーダーで正しく解釈できるLaTeX記法のサブセットです。ビルドはPandoc経由で行われ、1つのソースから以下の2つの成果物が生成されます。

\begin{itemize}
    \item PDF：Pandocが内部でLaTeXソースを生成し、LuaLaTeX（文書クラスはjlreq）でコンパイルします。組版品質の高い、印刷・配布向けの版です。
    \item HTML：PandocがHTMLを生成します。数式はMathJaxで描画されます。ブラウザでそのまま読め、翻訳機能や検索機能が使える版です。
\end{itemize}

LuaLaTeXで直接コンパイルする方式ではないため、自由にLaTeXパッケージを使うことはできません。使える記法は\cref{sec:writing_rules}を参照してください。

\section{環境構築}
Dev Containerによって開発環境をまるごとコンテナ化することで、面倒な環境構築を回避しつつ、本ドキュメントを編集することができます。ただし、依然としてコンテナを動かすための環境構築は必須であり、ここではその方法を説明します。

Dev Containerについてのより詳しい解説はVisual Studio Codeのウェブサイト（\url{https://code.visualstudio.com/docs/devcontainers/containers}）を参照してください。ここでの説明はこのサイトの和訳と抜粋にすぎません。

\subsection{Dockerのインストール}
\subsubsection{Windowsにインストールする場合}
Docker Desktopをインストールしてください。WindowsのエディションがHomeの場合はWSL2機能を有効にする必要があります。

\subsubsection{Windows上のWSL2（Ubuntu）にインストールする場合}
\begin{enumerate}
    \item 以下2つをインストールしてください。具体的な方法はそれぞれのウェブサイトを参照してください。
    \begin{itemize}
        \item Docker Engine: \url{https://docs.docker.com/engine/install/ubuntu/}
        \item Docker Compose: \url{https://docs.docker.com/compose/install/linux/}
    \end{itemize}
    \item \texttt{sudo usermod -aG docker \$USER}を実行してください。
    \item Ubuntuの再起動をかけてください。
\end{enumerate}

\subsection{Visual Studio Code（VS Code）のインストール}
\begin{enumerate}
    \item Windows上にVS Code本体をインストールしてください。
    \item VS Code上の拡張機能を以下2つインストールしてください。偽の拡張機能（マルウェアの可能性があります）に注意してください。
    \begin{itemize}
        \item Dev Containers extension: \url{https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers}
        \item Remote Development extension pack: \url{https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.vscode-remote-extensionpack}
    \end{itemize}
\end{enumerate}

\subsection{Gitの設定}
WindowsもしくはWSL2（Ubuntu）上にGitがインストールされているのは前提とします。ローカルにユーザー名とメールアドレスが適切に設定されていることを確認してください。
\begin{quote}
    \texttt{git config --global user.name "Your Name"}

    \texttt{git config --global user.email "your.email@address"}
\end{quote}

Dev Containerでは、適切に設定すれば、コンテナの内部でも上手くGitを使うことができます。詳細はVS Codeのウェブサイト（\url{https://code.visualstudio.com/remote/advancedcontainers/sharing-git-credentials}）にある通りです。「Using a credential helper」というのが楽だと思います。これはつまりGitHubのウェブサイト（\url{https://docs.github.com/ja/get-started/getting-started-with-git/caching-your-github-credentials-in-git}）を参照せよということなので、これに従ってください。

\subsection{ローカル環境で直接ビルドする場合}
Dev Containerを使わず、自分のマシンで直接ビルドする場合は、以下の2つをインストールしてください。

\begin{itemize}
    \item Pandoc: \url{https://pandoc.org/installing.html}
    \item TeX Live: \url{https://www.tug.org/texlive/} （\texttt{lualatex}, \texttt{jlreq}, \texttt{luatexja-preset}, \texttt{titlepic} 等を含むフルインストールを推奨）
\end{itemize}

\section{作業方法}
\begin{enumerate}
    \item VS Code上でDigitShowDocが格納されたディレクトリを開いてください。
    \item Ctrl + Shift + Pのショートカットを利用し、「開発コンテナー：コンテナーでフォルダを開く」を選択してください。
    \item 現在のディレクトリと同じ、\texttt{./}ディレクトリを選択しOKを押してください。
    \item 任意の\texttt{.tex}ファイルを編集します。
    \item ビルドはVS Codeのタスク（Ctrl + Shift + B）から行えます。コマンドラインからは以下の通りです。
\end{enumerate}

PDFをビルドする場合：
\begin{lstlisting}[caption={PDFのビルドコマンド}]
pandoc --defaults=defaults-pdf.yaml
\end{lstlisting}

HTMLをビルドする場合：
\begin{lstlisting}[caption={HTMLのビルドコマンド}]
pandoc --defaults=defaults-html.yaml
\end{lstlisting}

これらはそれぞれ、リポジトリ直下の\texttt{main.pdf}と\texttt{main.html}を上書きで生成します。

\section{書くときのルール}
\label{sec:writing_rules}
Pandocが解釈できるLaTeX記法のサブセットのみが使えます。PDFとHTMLの両方で正しく表示されることが絶対条件です。基本的には``文書の見た目（スタイル）ではなく構造（意味や役割）''を意識してください。

\subsection{使える記法}
\begin{itemize}
    \item 章・節：\texttt{\textbackslash chapter}, \texttt{\textbackslash section}, \texttt{\textbackslash subsection}, \texttt{\textbackslash subsubsection}。番号は自動で付きます。
    \item ラベルと参照：章節には\texttt{\textbackslash label\{sec:...\}}、図には\texttt{\textbackslash label\{fig:...\}}、表には\texttt{\textbackslash label\{tab:...\}}のように、何のラベルかを冒頭で示すと便利です。参照には\texttt{\textbackslash cref}または\texttt{\textbackslash ref}を使ってください。Pandocが番号を解決し、PDFではハイパーリンク付きの番号、HTMLではリンクに変換されます。
    \item 図：figure環境と\texttt{\textbackslash includegraphics}が使えます。\texttt{\textbackslash label}は必ず\texttt{\textbackslash caption\{...\}}の中に書いてください。
    \item 表：tabular環境とbooktabsパッケージの罫線（\texttt{\textbackslash toprule}, \texttt{\textbackslash midrule}, \texttt{\textbackslash bottomrule}）が使えます。図と同様、\texttt{\textbackslash label}は\texttt{\textbackslash caption\{...\}}の中に書いてください。
    \item リスト：itemize, enumerate, description環境が使えます。
    \item 強調：太字にしたいときも、見た目ではなく意味を優先し、\texttt{\textbackslash emph}を使ってください。\emph{強調はこのように}表示されます。
    \item インラインコード：コードやファイル名、ディレクトリをインラインで書きたいときは\texttt{\textbackslash texttt}を使ってください。ただし、\emph{キャプションや節タイトルの中では使わないでください}（PDFビルドが失敗します）。
    \item コードブロック：lstlisting環境が使えます。言語とキャプション（ファイル名など）をオプションで指定してください。
    \item 数式：\texttt{\$...\$}によるインライン数式と、align環境によるディスプレイ数式が使えます。HTMLではMathJaxで描画されます。
    \item 引用符：ダブルクオーテーションマークで括るときは、\texttt{"}で括るのではなく\texttt{``}と\texttt{''}で括ると形が整います。
    \item リンク：\texttt{\textbackslash url\{...\}}が使えます。
\end{itemize}

コードブロックの記述例：
\begin{lstlisting}[language=C++,caption={DigitShowModbus.cpp}]
#include "DigitShowModbus.h"

#define _USE_MATH_DEFINES
#include <math.h>
\end{lstlisting}

\subsection{数式・単位の書き方}
\begin{itemize}
    \item 単位つきの数値は、次のように直接数式として書いてください（出力例：$100\,\mathrm{kPa}$）。siunitxパッケージ（\texttt{\textbackslash qty}, \texttt{\textbackslash si}, \texttt{\textbackslash unit}など）は使えません。
    \begin{lstlisting}
$100\,\mathrm{kPa}$
    \end{lstlisting}
    \item 自動伸縮する括弧は\texttt{\textbackslash left( \textbackslash right)}のように書いてください。physics2パッケージの\texttt{\textbackslash ab}は使えません。
    \item 数式の中で日本語や単語を書くときは\texttt{\textbackslash text\{...\}}で囲んでください（HTMLのMathJaxで正しく表示するため）。例：\texttt{\$E \&= \textbackslash text\{印加電圧\}\$}。
    \item イタリック体と立体（ローマン体）の使い分けに注意しましょう。例えばイタリック体で$ABC$と書くと$A\times B\times C$と解釈されますが、立体で$\mathrm{ABC}$と書くとABC（一つの数）と解釈されます。添え字も$h_\mathrm{init}$のように立体にすることが多々あります。数式モードで立体にするには\texttt{\textbackslash mathrm\{\}}を使います。
\end{itemize}

\subsection{使えない記法（代替手段）}
\begin{itemize}
    \item siunitxパッケージ → 上述の通り、数式で直接書いてください。
    \item physics2パッケージ（\texttt{\textbackslash ab}など） → \texttt{\textbackslash left( \textbackslash right)}を使ってください。
    \item tcolorboxパッケージ → 代替機能はありません。通常の段落・リスト・コードブロックで表現してください。
    \item cleverefパッケージの設定（\texttt{\textbackslash crefname}など） → \texttt{\textbackslash cref}コマンド自体は使えますが、表示名のカスタマイズはできません。
    \item TikZパッケージ → HTMLでは表示されません。図が必要な場合は事前に画像（PNG）としてレンダリングし、\texttt{img/}ディレクトリに置いて\texttt{\textbackslash includegraphics}で読み込んでください。本ドキュメントの\texttt{img/precon\_q\_rpm.png}もこの方法で作成しています。
    \item 独自の\texttt{\textbackslash newcommand}による見た目のカスタマイズ → Pandocの解釈が保証できないため避けてください。
    \item \texttt{\textbackslash maketitle}, \texttt{\textbackslash tableofcontents} → main.texには書きません。タイトルページと目次はPandocがビルド設定（defaults-pdf.yaml / defaults-html.yaml）に基づいて自動生成します。
\end{itemize}

\subsection{文章表現}
\begin{itemize}
    \item 好みの問題に近いですが、和文では全角記号を使うと見た目が整うように思います。例えば括弧類（）やコロン：など。和文の中に英数字を含めなければいけない場面では臨機応変に対応しましょう。
\end{itemize}
